- No paid services: books come from Project Gutenberg (Gutendex catalog, proxied via server functions), translation from the free MyMemory API in the browser, audio from browser speech. Why: user requires zero hosting/API cost.
- All user data (progress, streak, saved words, uploaded books) is stored on-device (localStorage + IndexedDB); no accounts. Why: user chose device-only storage.
